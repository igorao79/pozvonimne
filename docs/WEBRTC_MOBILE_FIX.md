# Исправление WebRTC звука на мобильных устройствах

## Проблемы

### 1. Основная проблема (решена)
WebRTC звонки подключаются на мобильных телефонах, но звука не слышно. Это связано с ограничениями браузеров на автовоспроизведение аудио без взаимодействия пользователя.

### 2. Новая проблема: Компьютер → Телефон (решена)
При звонках с компьютера на телефон:
- ✅ Голос с телефона передается на компьютер
- ❌ Голос с компьютера НЕ передается на телефон (вечная тишина)
- ✅ Звонки компьютер ↔ компьютер работают нормально

**Причина**: Различия в настройках аудио кодеков и параметров обработки между десктопом и мобильными устройствами.

- **Файл**: `src/hooks/useWebRTC/peerConfig.ts`  
- **Изменения**:

1. Автоматическое определение мобильного устройства
2. Платформо-специфичные настройки аудио
3. Множественные попытки восстановления
4. Детальное логирование в консоли

## Основные улучшения

### AudioContext разблокировка
```javascript
// Немедленная попытка разблокировки при загрузке потока
unlockAudio().then(() => {
  console.log('📱 Audio context unlocked')
}).catch(err => {
  console.warn('📱 Audio context unlock failed:', err)
})
```

### Направление аудио
```javascript
// Автоматическое переключение на динамик на Android
if (isAndroidDevice()) {
  await setSpeakerOutput(remoteAudioRef.current)
}
```

### Восстановление после ошибок
```javascript
// Автоматическая попытка восстановления
setTimeout(async () => {
  const currentStream = remoteAudioRef.current.srcObject
  remoteAudioRef.current.srcObject = null
  await new Promise(resolve => setTimeout(resolve, 500))
  remoteAudioRef.current.srcObject = currentStream
  await forcePlayAudio(remoteAudioRef.current)
}, 1000)
```

## Рекомендации для пользователей

### iOS (Safari/Chrome):
- Убедитесь, что переключатель звонок/бесшумный режим в положении "звонок"
- Попробуйте Safari вместо Chrome
- Проверьте громкость устройства

### Android (Chrome/Firefox):
- Отключите Bluetooth наушники
- Проверьте настройки "Не беспокоить"  
- Очистите кеш браузера при проблемах

### Общие советы:
- Разрешите доступ к микрофону в настройках браузера
- Проверьте стабильность интернет-соединения
- Перезагрузите браузер/приложение при стойких проблемах
