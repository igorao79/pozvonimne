# Настройка Email-шаблонов в Supabase

## Инструкция по настройке шаблона подтверждения регистрации

### 1. Войдите в панель Supabase
1. Перейдите на [supabase.com](https://supabase.com) и войдите в свой проект
2. В левом меню выберите **Authentication** > **Email Templates**

### 2. Настройте шаблон "Confirm signup"
1. Выберите **"Confirm signup"** в списке шаблонов
2. В поле **"Subject heading"** вставьте:
   ```
   Подтвердите Вашу регистрацию на Позвони.мне!
   ```

3. В поле **"Message body"** вставьте содержимое файла `email-templates/signup-confirmation-ru.html`

### 3. Настройте Redirect URLs
1. Перейдите в **Authentication** > **URL Configuration** 
2. В поле **"Site URL"** укажите: `https://pozvonimne.vercel.app`
3. В поле **"Redirect URLs"** добавьте все необходимые URL:
   ```
   https://pozvonimne.vercel.app/auth/callback
   https://pozvonimne.vercel.app/auth/confirm
   https://pozvonimne.vercel.app
   http://localhost:3000/auth/callback
   http://localhost:3000/auth/confirm  
   http://localhost:3000
   ```

⚠️ **ВАЖНО**: Убедитесь, что Site URL настроен правильно. Если он установлен как `localhost:3000`, все подтверждения будут перенаправлять на локальный сервер!

### 4. Проверьте настройки
1. Нажмите **"Save"** для сохранения шаблона
2. Нажмите **"Send test email"** для проверки (опционально)

## Переменные шаблона

В шаблоне используются следующие переменные Supabase:

- `{{ .ConfirmationURL }}` - ссылка для подтверждения email
- `{{ .SiteURL }}` - URL вашего сайта
- `{{ .Email }}` - email адрес пользователя
- `{{ .Token }}` - токен подтверждения (если нужен)
- `{{ .TokenHash }}` - хеш токена (если нужен)

## Что происходит после подтверждения

1. Пользователь кликает на ссылку в письме
2. Supabase перенаправляет на `/auth/callback`
3. Middleware обрабатывает запрос и перенаправляет на `/auth/confirm`
4. Страница подтверждения показывает красивую анимацию успеха
5. Автоматический редирект на главную страницу через 5 секунд

## Дополнительные настройки

### Локализация других шаблонов
Аналогично можно настроить другие email-шаблоны:
- **Magic Link** - для входа по ссылке
- **Reset Password** - для сброса пароля
- **Change Email Address** - для смены email

### Тестирование
Для тестирования email-шаблонов:
1. Зарегистрируйте тестового пользователя
2. Проверьте, что письмо приходит с правильным содержимым
3. Убедитесь, что ссылка ведет на правильную страницу подтверждения

## Troubleshooting

### Проблема: Письма не приходят
- Проверьте настройки SMTP в Supabase
- Убедитесь, что email не попал в спам
- Проверьте логи в Supabase Dashboard

### Проблема: Ссылка не работает
- Убедитесь, что Redirect URLs настроены правильно
- Проверьте, что middleware.ts корректно обрабатывает редиректы
- Проверьте настройки CORS в Supabase

### Проблема: Стили не отображаются
- Inline CSS должен работать в большинстве email-клиентов
- Некоторые клиенты могут блокировать определенные стили
- Тестируйте в разных email-клиентах
