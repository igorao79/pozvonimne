# Решение проблем с Electron приложением

## 🚨 Проблема: Бесконечная загрузка в Electron

### Причины и решения:

### 1️⃣ **Синтаксические ошибки в коде**
**Проблема:** Ошибки в JavaScript/TypeScript файлах
**Решение:** 
- Исправлены синтаксические ошибки в `src/app/page.tsx`
- Добавлена обработка ошибок инициализации

### 2️⃣ **Electron загружает статические файлы вместо dev сервера**
**Проблема:** Electron пытается загрузить `file://` вместо `http://localhost:3000`
**Решение:** 
- Изменена логика загрузки в `electron/main.js`
- Принудительное использование localhost в development режиме
- Добавлена проверка доступности Next.js сервера

### 3️⃣ **Next.js сервер не готов при запуске Electron**
**Проблема:** Electron запускается раньше, чем Next.js сервер готов
**Решение:**
- Создан `electron/dev-server.js` для последовательного запуска
- Добавлена задержка и проверка готовности сервера
- Автоматический retry при недоступности сервера

## 🚀 Способы запуска:

### Вариант 1: Автоматический запуск (Рекомендуется)
```bash
npm run dev:electron
```
Автоматически запускает Next.js сервер, ждет его готовности и запускает Electron.

### Вариант 2: Ручной запуск
```bash
# Терминал 1
npm run dev

# Терминал 2 (после "Ready on http://localhost:3000")
npm run electron:dev
```

### Вариант 3: Standalone режим
```bash
npm run build
npm run electron:standalone
```
Использует встроенный сервер без внешних зависимостей.

## 🔧 Диагностика проблем:

### Проверка статуса Next.js сервера:
```bash
curl http://localhost:3000
# или в браузере: http://localhost:3000
```

### Проверка логов Electron:
- Откройте DevTools в Electron (Ctrl+Shift+I)
- Проверьте консоль на ошибки
- Посмотрите Network tab на запросы

### Проверка портов:
```bash
netstat -an | findstr 3000
```

## 📋 Чек-лист при проблемах:

1. ✅ **Next.js сервер запущен?**
   - Проверьте, что `npm run dev` показывает "Ready on http://localhost:3000"

2. ✅ **Порт 3000 свободен?**
   - Убедитесь, что нет конфликтов портов

3. ✅ **Переменные окружения настроены?**
   - Проверьте `.env` файл с Supabase credentials

4. ✅ **Нет синтаксических ошибок?**
   - Проверьте консоль Next.js на ошибки компиляции

5. ✅ **Firewall не блокирует?**
   - Разрешите подключения к localhost:3000
